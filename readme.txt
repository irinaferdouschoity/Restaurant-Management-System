RESTAURANT MANAGEMENT SYSTEM
============================

SETUP INSTRUCTIONS:
1. Start XAMPP (Apache + MySQL)
2. Create database 'restaurant_system' in phpMyAdmin
3. Import database_setup.sql
4. Place project in: C:\xampp\htdocs\restaurant-system\
5. Add food images to images/food/ folder
6. Add staff images to images/staff/ folder

ACCESS:
- User Site: http://localhost/restaurant-system/
- Admin Panel: http://localhost/restaurant-system/admin/login.php
- Admin Login: admin / admin123

BACKUP:
- Regular backup: Export database from phpMyAdmin
- File saved as: restaurant_system_backup.sql
